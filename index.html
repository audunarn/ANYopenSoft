Full End-to-End FEM Program v0.3.0

ANYfem

Full end-to-end finite element program designed specifically for shell and beam structures. Provides a complete workflow covering geometric modeling (nodes, shell surfaces, beam axes, loads, boundary conditions), FE solving (element stiffness assembly, linear static and non-linear solver execution via ANYsolver), and interactive postprocessing (von Mises stress contours, principal stresses, displacements, beam axial forces, shear forces, and bending moments).

01. MODELING Parametric shell surface & beam axis geometry, mesh density, nodal loads, line loads, and boundary conditions.
02. SOLVING Assembly of quad/tri shell & 2-node beam stiffness matrices; linear static and non-linear static/arc-length solver runs.
03. POSTPROCESSING Interactive 3D visualization of von Mises stress contours, deflections, beam axial/bending force diagrams.
Full FEM Workflow Shell Elements (Quad/Tri) Beam Elements (2-Node) Linear & Non-Linear Static Postprocessing Engine
pip install ANYfem

Flagship Steel Structure App v6.1.1

ANYstructure

Desktop steel-structure design application for plate fields and cylinders with integrated weight, weld, and cost optimization. Implements prescriptive scantling rules and buckling checks under DNV-OS-C101 (thickness, section modulus, shear area), DNVGL-RP-C201 (plate buckling), DNV-RP-C202 (shell buckling), and DNVGL-RP-C203 (fatigue). Integrates direct calculation engine coupling via ANYsolver.

DNV-OS-C101 DNV-RP-C201 / C202 DNVGL-RP-C203 Stiffened Panels Cylindrical Shells Scantling Optimization

Calculation Engine v0.2.5

ANYsolver

Finite element calculation engine runtime specializing exclusively in shell and beam elements. Supports linear static analysis, arc-length continuation path solver for non-linear load-deflection paths, follower pressure loads on current deformed area, von Karman or corotational shell kinematics, non-linear prestress, and buckling capacity recovery. Exposed via public contract resolve_runtime_analysis().

Calculation Engine Shell & Beam Specialist Linear Static Analysis Arc-Length Path Solver Follower Pressure Corotational Shells

ANYbuckling

Calculation Engine

Standalone calculation engine extracted from ANYstructure (no GUI, depends only on NumPy & SciPy). Implements prescriptive flat-plate buckling under DNV-RP-C201 (anybuckling.FlatStru), cylindrical shell buckling under DNV-RP-C202 (anybuckling.CylStru), and PULS-type S3/U3 semi-analytical solver (anybuckling.semianalytical) for ultimate capacity assessments.

ANYbuckling Python Usage Example 
from anybuckling import FlatStru

# Initialize DNV-RP-C201 stiffened panel calculation
panel = FlatStru('Flat plate, stiffened')
panel.set_material(mat_yield=355, emodule=210000, material_factor=1.15, poisson=0.3)
panel.set_plate_geometry(spacing=680, thickness=12, span=3300)
panel.set_stresses(pressure=0.01, sigma_x1=120, sigma_x2=120, sigma_y1=40, sigma_y2=40, tau_xy=25)
panel.set_stiffener(hw=260, tw=12, bf=49, tf=28, stf_type='bulb', spacing=680)
panel.set_buckling_parameters(calculation_method='DNV-RP-C201 - prescriptive', buckling_acceptance='ultimate')

results = panel.get_buckling_results()
print('Plate Buckling Usage Factor:', results['Plate']['Plate buckling'])

Popular Discussion Topics & FAQ

How does ANYbuckling implement PULS S3/U3 semi-analytical capacity?

ANYbuckling includes the semi-analytical panel capacity solver in anybuckling.semianalytical, evaluating incremental non-linear orthotropic plate deflection fields without requiring full 3D solid discretization.

How are linear vs non-linear arc-length analyses configured in ANYsolver?

Via resolve_runtime_analysis(), pass solver mode 'arc_length' to trace post-buckling snap-through load-deflection equilibrium paths with automatic constraint step sizing.

Can ANYtimeseries process non-marine time-series data?

Yes. ANYtimeseries is designed for all generic time series: statistical distributions, power spectral density (PSD) estimation, peak detection, and rainflow cycle counting.
