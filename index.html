Core Ecosystem Pillars

Main Interconnected & Standalone Software

`ANYstructure`, `ANYfem`, and `ANYsolver` form the primary interconnected structural analysis stack, accompanied by `ANYtimeseries` for standalone offshore environmental load analysis.

Flagship Application

ANYstructure

Desktop steel-structure design application for plate fields and cylinders with integrated weight, weld, and cost optimization. Implements DNV-OS-C101, DNVGL-RP-C201, DNV-RP-C202, and full FE GUI solver coupling.

DNV Standards Optimization Tkinter GUI 3D CAD / IFC FE Integration
pip install ANYstructure

Complete Ecosystem

All ANYopenSoft Modules & Libraries

Modular Python calculation engines, geometry authorities, material databases, and meshing toolkits.

ANYbuckling

Engine

Standalone calculation engine for prescriptive (DNV-RP-C201, DNV-RP-C202) and semi-analytical (PULS S3/U3) buckling capacity of stiffened panels and cylindrical shells.

DNV-RP-C201 DNV-RP-C202 PULS S3/U3 No-GUI
pip install ANYbuckling

ANYgeometry

Geometry

Shared neutral surface-geometry authority and parametric 3D CAD generator for plate fields, stiffened panels, cylinders, cones, and structural assemblies.

Neutral Cad Parametric Geometry Model
pip install ANYgeometry

ANYmaterial

Material

Material property authority and database. Provides structural steel definitions, DNV material factors, temperature curves, and orthotropic property structures.

DNV Materials Yield Stress Orthotropic
pip install ANYmaterial

ANYmesh

Mesher

2D/3D mesh generation and meshing control library. Generates finite element quad/tri meshes for stiffened panels and shell structures.

FE Meshing Quad / Tri Elements Mesh Controls
pip install ANYmesh

ANYio

Data I/O

Neutral file import/export library, IFC 3D product conversion, file format inspectors, and external CAD exchange pipeline handlers.

IFC 3D Export Neutral File I/O Format Inspector
pip install ANYio

ANYtk3D

3D Visualizer

Lightweight 3D CAD geometry and FE mesh visualization widgets designed for Python Tkinter desktop GUIs and interactive rendering.

Tkinter Widget 3D Rendering Mesh Viewer
pip install ANYtk3D

Quick Start & Local Setup

Get started with individual PyPI packages or set up the full editable development environment.

Install packages via pip 
# Install the main flagship desktop application
pip install ANYstructure

# Or install individual calculation engines
pip install ANYbuckling
pip install ANYtimeseries
Local editable workspace setup (PowerShell) 
# Create and activate virtual environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1

ANYstructure
ANYbuckling Python Usage Example 
from anybuckling import FlatStru

# Initialize DNV-RP-C201 stiffened panel calculation
panel = FlatStru('Flat plate, stiffened')
panel.set_material(mat_yield=355, emodule=210000, material_factor=1.15, poisson=0.3)
panel.set_plate_geometry(spacing=680, thickness=12, span=3300)
panel.set_stresses(pressure=0.01, sigma_x1=120, sigma_x2=120, sigma_y1=40, sigma_y2=40, tau_xy=25)
panel.set_stiffener(hw=260, tw=12, bf=49, tf=28, stf_type='bulb', spacing=680)
panel.set_buckling_parameters(calculation_method='DNV-RP-C201 - prescriptive', buckling_acceptance='ultimate')

results = panel.get_buckling_results()
print('Plate Buckling Usage Factor:', results['Plate']['Plate buckling'])
