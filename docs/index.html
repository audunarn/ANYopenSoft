Product 01

ANYstructure

Desktop application for steel structure design. Model plate fields and cylinders, run DNV-based rule calculations, and take the design through to weight, weld and cost optimization in one workflow.

  • Plate field and cylinder modeling
  • DNV-based rule calculations
  • Load definition and reporting
  • Weight, weld and cost optimization
Source on GitHub Documentation

Product 02

ANYtimeseries

Desktop application for exploring, editing and analyzing time-series data. Import measurements, apply transformations and filters, and go from raw signal to plotted result without leaving the tool.

  • Data import
  • Transformations and filtering
  • Statistics and plotting
  • Interactive exploration and editing
Source on GitHub Documentation

About

Method you can open.

ANYopenSoft develops desktop engineering software in public repositories. Every application is focused, documented and maintained where the engineering community can read the code behind the results.

  • Structural assessment

    Rule-based strength checks for plate fields and cylinders in ANYstructure.

  • Optimization

    Weight, weld and cost trade-offs explored directly in the structural model.

  • Signal processing

    Transformations and filters applied to imported measurement data in ANYtimeseries.

  • Visualization

    Statistics and plots that turn raw series into reviewable results.
